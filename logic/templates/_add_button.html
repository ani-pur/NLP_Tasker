{# Loading animation for the Add task button, for the default theme (glass_desktop + glass_mobile). While a task is being parsed, an arc of light circles the button in the task's own color (the theme accent when the task has none). The page's button needs these children: Add task and gets: const finish = addBtnStart(btn, hex) disables the button and starts the loading state await finish(ok) plays the saved / failed ending, then re-enables the button The animation runs on its own clock: the page updates the list, the input and the ambient light as soon as the reply arrives, and only waits on finish() when it needs to (the alert after a failure). Loading always shows for at least AB_MIN_LOADING_MS, so a quick reply never just flickers. #}
