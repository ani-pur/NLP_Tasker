{# Color picker for the default theme (glass_desktop + glass_mobile): the palette as quick picks, plus a shade square, a hue strip and a hex box for any other color. Pointer events, so mouse, touch and pen all work; arrow keys too. A small popover next to whatever opened it. Needs _palette.html (TASK_PALETTE, NO_COLOR). Gives the page: openColorPicker(anchorEl, hex, { onInput(hex), onDone(hex), onCancel() }) live updates while dragging; Esc reverts syncSwatches(containerEl, hex) marks the matching swatch, or the [data-custom] one for any other hex placeNear(el, anchorEl, align) positions a fixed popover by its button (also used by _canvas_feed.html) #}
